## 高亮修复返工：根因是 docsify 内置 Prism 覆盖 window.Prism（同日追加）

用户反馈引入后"还是没有高亮"。下载 docsify@4.13.1 源码排查，**根因找到**：

- docsify 4.x **npm 依赖打包了一份 Prism 核心**，脚本末尾执行 `window.Prism=Pn` 覆盖全局。
- 之前把 `prism.min.js` + 语言组件放 docsify **之前**：语言组件注册在外部核心上 → docsify 加载后 window.Prism 被换成内部核心（只含 markup/css/clike/javascript）→ `Prism.languages.sql` 不存在 → `renderer.code` 回退 `languages.markup` 高亮 sql → 看起来"没高亮"。
- **修复**：不引 `lib/prism.min.js`（docsify 自带核心），**10 个语言组件全部移到 docsify CDN 之后**；删除多余的 doneEach 钩子（docsify 渲染时内置自动高亮）。
- node 模拟验证：核心后加载组件 → `languages.sql/python/bash` 均注册成功，`highlight()` 输出 token span ✓；资源全 200。
- 清理临时探测文件 `_docsify_probe.min.js`（python os.remove，Windows 下 rm 又遇 genie-trash 路径 bug）。
