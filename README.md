## 一些个人的思考

对于程序员来讲, <mark class="blue">AI时代</mark>是一场非常大的变革, 甚至我认为会成为<mark class="red">老程序员的一种护城河</mark>

在过去, 一个<mark class="green">初学者</mark>如果想进入程序员这个行业, 他首先要经历<mark class="orange">漫长痛苦的基础学习</mark>

但 AI 打破了这个过程, 并且我也发现, 越来越多人开始提倡<mark class="yellow">基础无用论</mark>

<mark class="purple">"既然AI可以帮我写代码, 为什么我还要从头开始学?"</mark>

他们认为这是一种非常<mark class="orange">低效</mark>的方式, 与其花费时间学习, 不如<mark class="orange">多烧点token</mark>, 反正无论什么问题, 多问几遍 AI 就能解决

所以才出现了一些很可笑的场面, 比如有人遇到bug, <mark class="red">只能描述看到的现象</mark>, 却不能描述具体的问题, 以及排查思路

这个过程就变成了: <mark class="gray">描述现象 > AI猜原因 > 尝试> 失败 > 再描述 > 再次猜原因 > 反复尝试</mark>

但是资深程序员会<mark class="blue">直接指明几个方向</mark>, 把排查的过程 这种体力活让 AI 去做, 然后讨论之后定解决方案, <mark class="green">要的是可控</mark>

<mark class="blue">掌控代码的能力</mark>至关重要, 想必企业也不会去要一个<mark class="red">不懂基础, 只会烧token的人</mark>
